- Redmine 주간보고에 작업 내용·이슈·조치 보충
  - 일감 설명란(사내 템플릿)의 "▶ 요건" 요청 내용을 일감 아래 하위 불릿으로 표시
  - "▶ 오류"·"▶ 개선/검토" 표에서 내용이 채워진 행을 `이슈: 내용 → 처리결과`, `개선: …` 형태로 표시
  - 설명란에 적힌 커밋 해시·브랜치 이름으로도 내 커밋을 일감에 연결 (브랜치에 일감 번호가 없어도 매칭)
  - 커밋 본문의 `- ` 항목을 커밋 줄 아래에 한 단계 더 들여 표시
  - 포맷 설정에 "설명란 작업 내용 포함", "커밋 본문 포함" 옵션과 줄 템플릿 추가
