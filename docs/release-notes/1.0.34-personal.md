  - macOS 자동 업데이트는 서명이 없어 동작하지 않을 수 있습니다. 새 버전은 dmg로 다시 설치하세요.
- Windows·macOS 설치본을 GitHub Actions에서 함께 빌드해 올립니다. Windows 자동 업데이트는 이전과 같습니다.
